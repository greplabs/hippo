Expand description

Reorders a set of already-retrieved candidates to improve precision.

Object-safe by design: no generic methods, no Self-by-value returns, so a &dyn Reranker / Arc<dyn Reranker> can be stored on the searcher and a different backend (heuristic today, a cross-encoder later) dropped in without touching the pipeline. Implementations must be cheap enough to run on every hybrid query over the top-N candidates.

fn rerank( &self, query: &str, candidates: Vec<MemorySearchResult>, ) -> Vec<MemorySearchResult>

Re-order candidates for query, best-first. Implementations may also overwrite each result’s score with the new rerank score; the caller treats the returned order (not the score magnitude) as authoritative.
