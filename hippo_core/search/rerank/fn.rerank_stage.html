Expand description

Apply the (gated) rerank stage to a fused, best-first result list.

This is the single entry point the search pipeline calls, kept as a free function so it is exhaustively testable offline:

  • enabled == false → identity (returns results untouched, i.e. today’s RRF order).
  • only the top rerank_candidates (by incoming fused order) are reranked; the tail keeps its RRF order and is appended unchanged. The combined list is NOT re-sorted, so the head (reranked) always precedes the tail.
