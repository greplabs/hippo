Runtime output dimension of the active TEXT embedding backend.

Qdrant collections should be created/validated against THIS value rather than a hardcoded constant, so that the stored collection dim always matches what the embedder actually emits.

pub fn similarity(a: &[f32], b: &[f32]) -> f32

Canonical cosine similarity between two embeddings.

All embeddings produced by this module are L2-normalized exactly once at generation time, so for such vectors the dot product IS the cosine similarity. Returns 0.0 on dimension mismatch.

NOTE: search::semantic_score, storage::cosine_similarity and duplicates::cosine_similarity are near-duplicates of this. Collapsing them into this one is a cross-module follow-up (those files are owned by other agents / depend on true-magnitude cosine in existing tests).
